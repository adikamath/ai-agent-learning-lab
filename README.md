# AI Agent Learning Lab

I’m using this repo to understand how AI agent systems work by building small projects from first principles, testing the underlying ideas, and comparing them with the abstractions used by popular agent platforms and frameworks. You can follow along with me at [adityakamath.com](https://adityakamath.com).

## What this is

This is a hands-on learning series built around small implementations and focused experiments. I’m interested in what makes an agent system work: how its parts fit together, where complexity appears, and which tradeoffs matter when shaping the infrastructure and product experience.

The goal is not to become an expert Python engineer or build a production-ready framework. It is to develop stronger technical intuition about agent infrastructure and the product decisions built on top of it.

## How I’m learning

**Learn → Build → Experiment → Compare → Reflect**

- **Learn:** Understand one core concept and the problem it addresses.
- **Build:** Create the smallest useful implementation that makes the concept concrete.
- **Experiment:** Change inputs, constraints, and components to see how the system behaves.
- **Compare:** Relate what I built to the abstractions used by relevant frameworks and platforms.
- **Reflect:** Capture the infrastructure lessons, product implications, and open questions.

## Areas I want to understand

These are areas I plan to explore through the projects, not topics I consider complete.

## Who this is for

This repo could also be useful for product managers, engineers, and other technical practitioners who want a clearer view of what sits underneath agent framework abstractions.
